# Aegis ICS - Empirical Benchmark Results

This directory contains experimental benchmark result datasets generated during synthetic attack simulation, hardware stress testing, and financial risk modeling.

## Datasets Index

| File | Size | Description | Generated By |
|---|---|---|---|
| [`stuxnet_attack_results.json`](stuxnet_attack_results.json) | ~113 KB | Time-series data of a Stuxnet-style frequency manipulation attack on centrifuge RPMs. Contains raw sensor readings, true underlying physics, Kalman filter estimates, and dynamic trust scores over 1,000 cycles. | Attack injection test suite / simulation runner |
| [`financial_risk_results.json`](financial_risk_results.json) | ~3.5 KB | Monte Carlo FAIR (Factor Analysis of Information Risk) simulation outputs (10,000 iterations), tracking expected financial loss, 95th percentile risk, and loss reduction with Aegis ICS. | `src/analytics.py` / FAIR evaluation script |
| [`nspn_decision_boundary.json`](nspn_decision_boundary.json) | ~100 KB | Neuro-Symbolic Petri Net reachability states, transition firing probabilities, and decision boundary points across 2D/3D sensor state spaces. | `src/nspn_engine.py` boundary probe |
| [`latency_benchmarks.json`](latency_benchmarks.json) | ~13 KB | Execution latency benchmarks across 50,000 sensor cycles measuring end-to-end processing times for Random Forest inference, NSPN invariant checking, Bayesian trust scoring, and alert dispatching. | Hardware latency benchmarker |
| [`trust_evolution_results.json`](trust_evolution_results.json) | ~49 KB | Multi-sensor trust score evolution profiles tracking sensor degradation, recovery after attack cessation, and threshold trip timing for 5 physical transducers. | Trust engine stress tests |

## Graph Generation

These JSON files serve as the input for `tests/generate_graphs.py`, which renders the corresponding publication figures into `docs/figures/`.
