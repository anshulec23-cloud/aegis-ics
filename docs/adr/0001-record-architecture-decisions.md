# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-13

## Context
The project grew over two years without a written rationale for its structure. Reviewers, new contributors and paper examiners can't tell which choices were deliberate.

## Decision
Record every significant architectural decision as an ADR in `docs/adr/`, using the template in `0000-template.md`.

## Consequences
A small writing cost per decision, in exchange for a durable record of intent. Retroactive ADRs (like 0002) capture the existing design.
